# Awesome iOS

A curated list of awesome iOS frameworks, libraries, tutorials & software.

## UI

### SwiftUI
* [Factory](https://github.com/hmlongco/Factory) - A modern Swift dependency injection framework.
* [SwiftUIIntrospect](https://github.com/siteline/SwiftUI-Introspect) - Introspect underlying UIKit/AppKit components from SwiftUI.
* [Lottie](https://github.com/airbnb/lottie-ios) - Render After Effects animations natively on iOS and macOS.
* [PopupView](https://github.com/exyte/PopupView) - Toasts and popups library written in SwiftUI.

## Architecture
* [The Composable Architecture (TCA)](https://github.com/pointfreeco/swift-composable-architecture) - A library for building applications in a consistent and understandable way.
* [Swift Clean Architecture](https://github.com/sergdort/CleanArchitectureRxSwift) - Clean Architecture sample with RxSwift.

## Cross-Platform
* [Flutter](https://github.com/flutter/flutter) - Google's SDK for crafting beautiful cross-platform apps.
* [React Native](https://github.com/facebook/react-native) - A framework for building native apps using React.
* [Skip](https://github.com/skiptools/skip) - Dual-platform Swift tool for creating native iOS and Android apps.
